# موقع رعد هادي عسيري

موقع تعريفي ثابت (HTML/CSS/JS) مبني من السيرة والشهادات المرفقة.

## الفتح محلياً
افتح ملف index.html في المتصفح.

## النشر
ارفع محتويات هذا المجلد إلى GitHub Pages أو Netlify بسحب المجلد.

## ملاحظات
- اللغة الافتراضية عربية مع زر تبديل إلى الإنجليزية.
- الشهادات المرفقة قابلة للعرض والتحميل.
- دورة بريمافيرا واختبار STEP مذكوران من السيرة بدون ملف مرفق.
